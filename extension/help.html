📌 小红书一键收录 · 使用帮助

三种使用方式

  1. A 点扩展图标 → 弹窗里可加备注、标签 → 点「收录到飞书」
  2. B 在小红书页面任意位置右键 → 选「📥 收录这条小红书笔记到飞书」
  3. C 切换标签页时，扩展图标会自动加 ✓ 徽标提示「已收录」

首次配置

  1. 点扩展图标右上角 ⚙️ 进入设置页
  2. API Endpoint：默认 http://14.22.112.147:8866
  3. Auth Token：王小熊会私聊发你一串字符，粘贴进来
  4. 点「🔌 测试连接」确认成功
  5. 「💾 保存」

状态徽标说明

  • ✓ 绿色 — 当前页笔记已经收录过
  • +1 绿色（1.5s 闪现）— 刚刚成功收录一条
  • ! 红色（1.5s 闪现）— 失败，可在弹窗里看详情
  • 无徽标 — 当前页未收录或不是小红书页

常见问题

1. 点了「收录」一直转圈 / 报「请求失败」

  • 检查服务器是否在线：浏览器打开 http://14.22.112.147:8866/api/health 应返回 {"ok":true}
  • 检查 token 是否匹配（设置页 → 测试连接）

2. 报「采集失败：未找到 __INITIAL_STATE__」

小红书前端结构可能临时变了，或这条笔记需要登录才能看。可以稍等几分钟再试，或者把链接拷出来手动看。

3. 报「⚠️ 这条笔记已经收录过」

K 列（笔记 ID）已经存在同一条。如需更新互动数，去飞书表手动清空该行 K 列再重新采集。

隐私与安全

  • 单条笔记收录：数据走王小熊服务器（14.22.112.147）写入你自己的飞书表
  • 账号全采集：插件先从主页提取最多前 400 篇完整笔记链接，服务端再用第三方单篇 API 逐篇采集并写入你的飞书表；API key 只放服务器，不放扩展
  • Auth Token 保存在浏览器本地存储里，每次收录会作为请求头发给王小熊服务器（不会发给小红书或其他同事）
  • 采集是无登录态，只看到笔记公开数据，不读你的小红书账号

📸 如何在飞书表添加「小红书收录助手」应用

这是 onboarding 第 3 步绑表前必做的授权操作。仅"协作者-可编辑"权限不够，必须按下面 7 步把 bot 加为「文档应用」，bot 才有写入权限给你建分类 sheet。

  1. 打开你的飞书表（任意一个 sheet 都行）
  2. 点击右上角的 ⋯（三个点菜单）
  3. 菜单底部找到 「更多」 → 鼠标悬停
  4. 点击展开的 「添加文档应用」
  5. 在搜索框里输入 「小红书收录助手」
  6. 点击应用 → 「添加」
  7. 添加后应用会显示在「已添加应用」里，且权限是「可管理」

⚠️ 常见误区：很多人以为在「文档权限」里把 bot 加为协作者就够了， 其实不行。飞书新版权限必须走「添加文档应用」这条路径，bot 才有写权限。
判断标准：在 onboarding 屏 3 点「🔍 检测 bot 权限」，显示 ✅ 才算授权成功。
