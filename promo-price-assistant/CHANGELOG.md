# 变更记录

## v1.0.0 - 2026-08-02

### 新增

- 新增独立的「小红书促销价助手」Chrome 扩展。
- 支持千帆站内跳转，只在单品特价页面显示操作面板。
- 支持95折上限、向下取9毛尾数的价格计算。
- 支持多商品、折叠规格和滚动表格扫描。
- 默认保护已有促销价，覆盖时二次确认。
- 支持价格预览、撤销、加载态、空状态和错误状态。
- 增加核心逻辑测试、权限合同测试和本地千帆模拟验收页。

### 安全边界

- 不连接服务器、飞书或第三方 API。
- 不自动点击千帆「创建」。
- 页面结构或价格无法识别时停止，不自动猜测。

### 待验收

- 安装到真实 Chrome 后，在登录状态的千帆单品特价页面完成端到端验收。
