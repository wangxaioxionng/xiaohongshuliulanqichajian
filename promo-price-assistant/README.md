# 小红书促销价助手

## 这个插件解决什么问题

在小红书千帆「新建/编辑单品特价」页面，自动扫描全部商品规格，按统一规则计算并填写促销价，减少人工逐行计算和漏填。

适用岗位：商品上架、店铺运营、活动配置人员。

## 固定价格规则

1. 先计算 `原价 × 95%`。
2. 再取不超过该上限、且以 `.9` 结尾的最高价格。
3. 示例：`90.2 × 95% = 85.69`，最终填写 `84.9`。

这样处理是因为千帆会拦截高于95折上限的价格；直接把 `85.69` 改成 `85.9` 会报错。

## 第一版功能

- 支持千帆单页应用内部跳转；脚本仅在 `ark.xiaohongshu.com` 运行，操作面板只在单品特价页面显示。
- 自动展开折叠商品并扫描滚动表格。
- 默认只填写空白促销价，不覆盖已有价格。
- 可查看修改前后的价格预览。
- 覆盖已有价格必须勾选开关并再次确认。
- 支持撤销本次填写。
- 填写后检查空值、95折上限和9毛尾数。
- 不读取或上传账号数据，不连接服务器和飞书。
- 永远不会自动点击「创建」。

## 安装方法

1. 打开 Chrome 扩展程序页面：`chrome://extensions/`。
2. 开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择**直接包含 `manifest.json` 的 `小红书促销价助手-v1.0.0` 文件夹**。

注意：不能选择 ZIP，也不能选择包住插件目录的外层文件夹，否则 Chrome 会提示「清单文件缺失或不可读取」。

## 使用方法

1. 登录千帆，进入「营销工具 → 新建单品特价」。
2. 添加商品后，右侧会出现「小红书促销价助手」。
3. 点击「扫描页面」，核对规格总数、待填写数和已有价格数。
4. 点击「查看价格预览」。
5. 点击「填写空白促销价」。
6. 页面校验通过后，由人工检查并决定是否点击千帆原生的「创建」。

## 状态说明

- 加载中：正在展开商品或读取滚动表格，暂时不能重复点击。
- 空状态：页面没有商品规格时提示先添加商品。
- 错误状态：原价无法识别、仍有空值或超过95折时，明确提示不要创建活动。
- 成功状态：只表示页面草稿已填写并通过插件校验，不代表活动已经创建。

## 已知限制

- 千帆页面结构更新后，插件可能无法识别表格；此时插件会停止并报错，不会猜价格。
- 真实页面首次安装验收必须在已登录的千帆账号中完成。
- 第一版固定为95折和9毛尾数，不提供其他折扣或尾数模板。
